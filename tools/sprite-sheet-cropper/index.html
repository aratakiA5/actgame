スプライトシート正規化ツール

最初に選んだマスのサイズを出力セルの基準にして、4×4へ結合します。
画像を選択してください。

1. 境界を調整して16フレームを選択

黄色い縦線・横線で現在のセル範囲を調整します。最初に選んだセルの幅・高さが出力セルの初期サイズになります。選択後の切り出し範囲は固定されます。

2. 4×4 配置

3. 選択フレーム調整

青枠フレームのみ調整します。個別の拡大/縮小率は出力全体の拡大縮小とは別です。

4. アニメプレビュー

指定した開始コマ〜終了コマをループ再生します。

5. 出力サイズ

仕様: 基準サイズは最初の選択セル / 出力全体を一括拡大縮小 / 4列×4行 / アスペクト比維持 / 透明余白 / 補間OFF。
