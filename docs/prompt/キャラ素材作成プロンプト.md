C# / MonoGame製の2D横スクロールアクションゲームで使用する、ヒロイン専用のキャラクタースプライトシートを作成してください。

目的は「実際にゲームへ組み込める素材」を作ることです。イラスト集や設定画ではなく、各フレームの位置とサイズが揃った、ゲーム用スプライトシートとして出力してください。

## 基本仕様

* 画像形式：PNG
* 背景：完全透過
* カラーモード：RGBA
* アンチエイリアス：なし
* 画像スタイル：32bit JRPG風 / 高品質ピクセルアート
* キャラクター：女性ヒロイン
* 向き：右向き
* 全フレームで同一人物・同一衣装・同一配色
* 武器は持たない
* 主な攻撃手段はキック
* キャラクターの頭身・体格・髪型・服装を全フレームで完全に統一
* フレームごとに身体の大きさを変えない
* キャラクターの足元位置を可能な限り統一する
* 影、背景、床、エフェクト文字、UI、枠線、説明文は描かない
* 他キャラクターを描かない

## スプライトシート全体サイズ

1フレーム：

* 幅：128 px
* 高さ：128 px

配置：

* 横8列
* 縦6行

スプライトシート全体：

* 幅：1024 px
* 高さ：768 px

各フレームは必ず128×128 pxのセル内に収めてください。

セル間の余白は0 pxとします。

## 座標ルール

画像左上を `(0, 0)` とします。

各フレームの切り出し座標は以下です。

* 列0：X = 0

* 列1：X = 128

* 列2：X = 256

* 列3：X = 384

* 列4：X = 512

* 列5：X = 640

* 列6：X = 768

* 列7：X = 896

* 行0：Y = 0

* 行1：Y = 128

* 行2：Y = 256

* 行3：Y = 384

* 行4：Y = 512

* 行5：Y = 640

各フレームの矩形は、

`X, Y, 128, 128`

です。

## キャラクター基準位置

全フレームで、キャラクターの足元中央をできるだけ次の位置に合わせてください。

* 足元基準X：64 px
* 足元基準Y：118 px

つまり、基本状態ではセル内の `(64, 118)` 付近が地面との接地点です。

ジャンプモーションを除き、足元位置を極端に上下させないでください。

キャラクター本体は通常、

* 左端：X 24〜40 px程度
* 右端：X 88〜104 px程度
* 頭頂：Y 10〜24 px程度
* 足元：Y 116〜120 px程度

に収めてください。

キック時に脚が大きく伸びる場合のみ、右端は最大124 pxまで使用可能です。

## 行0：待機モーション Idle

8フレーム。

フレーム0：
通常立ち姿。両足を自然に開き、軽く構える。

フレーム1：
胸と肩がわずかに上がる。

フレーム2：
髪が少し揺れる。

フレーム3：
重心がわずかに下がる。

フレーム4：
基本姿勢へ戻る。

フレーム5：
髪と上着が逆方向へ少し揺れる。

フレーム6：
呼吸で身体がわずかに上下する。

フレーム7：
フレーム0へ自然につながる姿勢。

待機モーションは大きく動かしすぎず、ループ再生したとき自然に見えるようにしてください。

## 行1：走りモーション Run

8フレーム。

右方向へ走るアニメーションです。

フレーム0：
右脚が前、左脚が後ろ。

フレーム1：
身体が沈み、右脚が接地。

フレーム2：
左脚が前へ移動中。

フレーム3：
左脚が前、右脚が後ろ。

フレーム4：
左脚が接地。

フレーム5：
右脚が前へ移動。

フレーム6：
右脚が前。

フレーム7：
フレーム0へ自然につながる中間姿勢。

髪と上着は走行方向とは逆側へなびかせてください。

足元の上下動は最大8 px程度にしてください。

## 行2：ジャンプモーション Jump

8フレーム。

フレーム0：
ジャンプ開始前のしゃがみ。

フレーム1：
蹴り出し。膝を伸ばして上昇開始。

フレーム2：
上昇中。両足が地面から離れる。

フレーム3：
上昇中。身体を少し縮める。

フレーム4：
ジャンプ頂点。最も高い姿勢。

フレーム5：
下降開始。

フレーム6：
着地直前。脚を伸ばす。

フレーム7：
着地。膝を曲げて衝撃を吸収。

この行では足元位置を固定しなくても構いませんが、キャラクター全体がセルからはみ出さないようにしてください。

## 行3：キックモーション Kick 1

この行は最重要です。

8フレームで、地上で行う基本の前蹴りを表現してください。

ゲーム内では右方向へ攻撃します。

### キック1 フレーム0

開始姿勢。

* 通常の戦闘構え
* 両足が地面についている
* 攻撃脚はまだ上げない
* 身体中心：X = 64 px付近
* 足元：Y = 118 px付近
* 攻撃判定なし

### キック1 フレーム1

予備動作。

* 攻撃する右脚の膝を前へ上げる
* 上半身を少し後ろへ引く
* 支持脚は地面に固定
* 右膝先端：X = 72〜82 px程度
* 攻撃判定なし

### キック1 フレーム2

蹴り出し開始。

* 右脚を前方へ伸ばし始める
* 腰を右へ回転
* 上半身は少し左へ傾ける
* 右足先：X = 90〜102 px程度
* 右足先Y = 62〜76 px程度
* 小さい攻撃判定開始

想定攻撃判定：

* X = 82
* Y = 54
* Width = 32
* Height = 38

### キック1 フレーム3

最大攻撃フレーム。

このフレームが最も重要です。

* 右脚をほぼ完全に水平へ伸ばす
* 足先は右方向
* 腰と肩をひねる
* 支持脚は地面に接地
* 上半身は左へ少し傾く
* 右足先X = 116〜124 px
* 右足先Y = 58〜70 px
* 膝X = 90〜100 px
* 腰X = 62〜68 px
* 足元基準X = 60〜66 px
* 足元基準Y = 118 px

このフレームでは、攻撃脚の先端がセル右端近くまで届くようにしてください。

想定攻撃判定：

* X = 88
* Y = 48
* Width = 40
* Height = 46

攻撃判定は太ももではなく、膝から足先を中心に考えます。

### キック1 フレーム4

最大伸展後。

* フレーム3と近い姿勢
* 足先を少し下げる
* 身体の回転が戻り始める
* 右足先X = 110〜120 px
* 右足先Y = 68〜80 px

攻撃判定：

* X = 90
* Y = 56
* Width = 34
* Height = 40

### キック1 フレーム5

脚を引き戻す。

* 膝を曲げる
* 右足を身体側へ戻す
* 足先X = 88〜98 px
* 攻撃判定なし

### キック1 フレーム6

着地。

* 攻撃脚を下ろす
* 両足が地面につき始める
* 上半身を正面へ戻す
* 攻撃判定なし

### キック1 フレーム7

通常構えへ完全復帰。

* Idleフレーム0に自然につながる
* 両足接地
* 攻撃判定なし

### キック1 全体の重要条件

開始時：

* 右足先はX = 70 px前後

最大攻撃時：

* 右足先はX = 116〜124 px

つまり、キックによって足先が約45〜50 px前方へ移動するようにしてください。

身体本体まで右へ移動させないでください。

攻撃中も支持脚の足元は、

* X = 56〜68 px
* Y = 116〜120 px

付近を維持してください。

キャラクター全体が右へスライドして見えないようにしてください。

フレーム2：

フレーム7：

空中キックでは両足が地面に接触しません。

## 行5：ダメージ・撃破・勝利

フレーム1：

## キャラクターデザイン

* 成人女性のアクションヒロイン
* 茶色または赤茶色の長いポニーテール
* 活発で勇敢な表情
* ピンク系の短いジャケット
* 黒系インナー
* 動きやすいショートパンツまたはスポーツ系衣装
* 黒系レギンスまたはタイツ
* ピンクまたは赤系スニーカー
* グローブ着用
* 格闘家らしい構え
* 過度な装飾は避ける
* スカートや長いマントなど、当たり判定を分かりにくくする衣装は避ける

## ピクセルアート仕様

* 輪郭線を明確にする
* 1〜2 px程度の濃いアウトライン
* ドットをぼかさない
* 高解像度イラストを縮小したような見た目は禁止
* 半透明のぼかしは禁止
* モーションブラーは禁止
* ピクセル単位で輪郭が読み取れること
* 各フレームで顔の大きさを統一
* 髪の長さを統一
* 脚の長さを統一
* 靴の大きさを統一

## 禁止事項

以下は絶対に行わないでください。

* キャラクターごとに服装が変わる
* フレームごとに髪型が変わる
* 左右反転したフレームを混ぜる
* キャラクターがセル境界を越える
* フレームの大きさが不揃い
* 背景を描く
* 影を描く
* 文字を書く
* フレーム番号を書く
* グリッド線を書く
* 攻撃エフェクトをキャラクターと一体化する
* 別の敵や人物を描く
* 足元位置をフレームごとに大きく変える
* キック時に身体全体が右へ移動する
* キックの足先がセル外にはみ出す
* 不要な武器を持たせる

## 出力条件

完成画像は、

* `heroine_spritesheet.png`
* PNG
* 1024×768 px
* RGBA
* 背景完全透過

として使用できる状態にしてください。

スプライトシート以外の説明画像、サンプル画面、一覧表、UI、モックアップは生成しないでください。

ゲームにそのまま読み込んで、

`Rectangle(column * 128, row * 128, 128, 128)`

で正確に切り出せるようにしてください。
